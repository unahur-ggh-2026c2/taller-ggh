# Recursos
## Módulo 00 — ¿Por qué Git?

Este módulo introduce los conceptos fundamentales que permiten comprender por qué resulta necesario utilizar un sistema de control de versiones.

Los recursos seleccionados tienen como finalidad ampliar las explicaciones y servir como material de consulta durante el resto del curso.

---

## 1. Documentación oficial de Git

### Git

Sitio oficial del proyecto Git.

https://git-scm.com/

Utilizar como referencia general para conocer el proyecto, su documentación y sus recursos oficiales.

---

## 2. Pro Git

**Chacon, S., & Straub, B. — Pro Git**

Libro de referencia sobre Git.

La versión en español está disponible gratuitamente en línea:

https://git-scm.com/book/es/v2

Para este módulo resulta especialmente útil como material de consulta sobre los fundamentos de Git y el concepto de control de versiones.

> No es necesario leer el libro completo para avanzar en el curso.

Si querés profundizar después de completar el módulo, investigá:

* control de versiones;
* sistemas de control de versiones;
* control de versiones distribuido;
* Git;
* repositorio;

El objetivo es poder explicar qué problema resuelve cada concepto y cómo se relaciona con los demás.

## 8. Para seguir pensando

Antes de avanzar al siguiente módulo, intentá responder:

> **¿Qué diferencia existe entre conservar muchas copias de un proyecto y conservar la historia de cómo ese proyecto evolucionó?**

Si podés explicar esa diferencia con un ejemplo concreto, ya tenés una buena base para comenzar a trabajar con Git.
