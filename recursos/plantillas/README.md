# Plantillas

Colección de plantillas reutilizables para trabajar con Git y GitHub.

Estas plantillas están pensadas como punto de partida. Adaptalas al proyecto, equipo o situación concreta.

---

## Contenido

| Archivo | Uso |
|---|---|
| [`README.md`](README.md) | Plantilla para documentar un proyecto |
| [`ISSUE.md`](ISSUE.md) | Plantilla para registrar tareas o problemas |
| [`PULL_REQUEST.md`](PULL_REQUEST.md) | Plantilla para presentar cambios a revisión |
| [`CASO-DE-ESTUDIO.md`](CASO-DE-ESTUDIO.md) | Plantilla para documentar un proyecto y su proceso |
| [`CHANGELOG.md`](CHANGELOG.md) | Plantilla para registrar cambios entre versiones |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Plantilla con pautas para contribuir a un proyecto |
| [`.gitignore`](.gitignore) | Plantilla inicial de exclusiones para proyectos Python |
| [`CHECKLIST-REPOSITORIO.md`](CHECKLIST-REPOSITORIO.md) | Checklist para revisar un repositorio antes de presentarlo |

---

## Cómo utilizarlas

Las plantillas no necesitan copiarse todas.

Elegí solamente las que tengan sentido para el proyecto.

Por ejemplo:

```text
Proyecto pequeño
├── README.md
└── .gitignore
```

Un proyecto con trabajo colaborativo podría incorporar:

```text
README.md
.gitignore
CONTRIBUTING.md
```

Y un proyecto desarrollado mediante Issues y Pull Requests podría utilizar además:

```text
ISSUE.md
PULL_REQUEST.md
```

---

## Importante

Estas plantillas son una base.

No es necesario conservar exactamente su estructura ni completar todas sus secciones.

El contenido debe adaptarse a:

* tamaño del proyecto;
* tipo de trabajo;
* cantidad de personas;
* necesidades de documentación;
* proceso de colaboración.

---

## Relación con otros recursos

Las plantillas cumplen una función diferente a los demás recursos del curso:

```text
cheatsheets/
    → consulta rápida

ejemplos/
    → referencia concreta

plantillas/
    → base reutilizable

ejercicios/
    → práctica opcional
```

Los ejemplos muestran cómo puede quedar un resultado.

Las plantillas proporcionan una base para construir uno propio.

---

## Uso recomendado

Antes de utilizar una plantilla:

```text
elegir
  ↓
copiar
  ↓
adaptar
  ↓
completar
  ↓
revisar
```

No copies contenido innecesario solamente porque aparece en la plantilla.

> **Una plantilla es un punto de partida, no un formulario obligatorio.**
