# Bibliografía

## 1. Bibliografía fundamental

### Pro Git

Chacon, S., & Straub, B. (2014). *Pro Git* (2.ª ed.). Apress.

Obra de referencia principal para los contenidos relacionados con Git. Se recomienda especialmente la versión disponible en español.

### Version Control with Git

Loeliger, J., & McCullough, M. (2012). *Version Control with Git* (3.ª ed.). O'Reilly Media.

Bibliografía complementaria para profundizar en el funcionamiento y utilización de Git como sistema de control de versiones.

---

## 2. Bibliografía complementaria

### Happy Git and GitHub for the useR

Bryan, J. (2024). *Happy Git and GitHub for the useR*.

Material de consulta orientado al aprendizaje práctico de Git y GitHub. Aunque originalmente desarrollado para usuarios del lenguaje R, presenta conceptos y flujos de trabajo aplicables de manera general al uso de Git y GitHub.

## 3. Documentación oficial

La documentación oficial constituye la principal fuente de consulta técnica para ampliar los contenidos del curso y continuar el aprendizaje de las herramientas.

### Git

**Git Documentation**

Documentación oficial del sistema de control de versiones Git.

Se recomienda priorizar la documentación disponible en español cuando el contenido se encuentre traducido.

### GitHub

**GitHub Docs**

Documentación oficial de GitHub sobre repositorios, colaboración, ramas, Pull Requests, autenticación, perfiles y demás funcionalidades de la plataforma.

Se recomienda utilizar la versión en español.

### Visual Studio Code

**Visual Studio Code Documentation**

Documentación oficial del entorno de desarrollo utilizado durante el taller.

### Markdown

**Markdown Guide**

Guía de referencia para la sintaxis y utilización de Markdown.

## 5. Material didáctico del curso

El material principal de estudio y práctica estará constituido por los contenidos desarrollados dentro de este repositorio.

Cada módulo contará con:

- guía de trabajo;
- actividades prácticas;
- ejercicios;
- desafíos;
- actividades de integración;
- recursos complementarios.

El material podrá ser actualizado de acuerdo con la evolución de las herramientas, las necesidades observadas durante las cursadas y la experiencia docente acumulada.

Las adaptaciones correspondientes a una institución o modalidad particular se documentarán en las respectivas guías docentes, sin duplicar ni modificar el material general del curso.

---

## 6. Criterio de utilización de la bibliografía

La bibliografía no tiene como objetivo que los estudiantes recorran exhaustivamente los materiales de referencia.

Su función principal es proporcionar:

1. una fuente conceptual para comprender los fundamentos de Git;
2. documentación técnica para resolver dudas;
3. material de profundización para quienes deseen avanzar más allá de los contenidos trabajados durante el curso;
4. fuentes confiables para continuar el aprendizaje autónomo.

Durante las actividades prácticas se priorizará la consulta de la documentación oficial y de los materiales elaborados específicamente para el curso.

> **La documentación no reemplaza la práctica: la acompaña.**
